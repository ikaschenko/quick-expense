How to generate Text-to-Speech:  Python edge-tts

Useful cmd line for text-to-speech: cmd> edge-tts --file demo_script.txt --voice en-US-AndrewMultilingualNeural --write-media demo3-en-US-AndrewMultilingualNeural.mp3
